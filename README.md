# 🏎️ 소수의 나눗셈 스피드 레이서 (6학년 2학기)

톨게이트에서 난이도를 고르고, 정답으로 부스터를 얻어 **10문제를 풀며 최단 시간에 완주**하는 학급용 웹 게임입니다.

## 규칙 요약
- 트랙 약 5,700m, 톨게이트 10개 (문제 10개). 칸막이가 있는 3개 길 중 하나로 들어가면 난이도가 정해집니다.
- 문제를 푸는 동안 차는 멈추지만 **전체 타이머는 계속 흐릅니다.**
- 정답: 난이도별 부스터 (쉬움 ×1.3 2.0초 / 보통 ×1.6 3.0초 / 어려움 ×2.3 4.5초). 부스터 시간은 달리는 동안에만 줄어듭니다.
- 오답: 감속 없이 **그 자리에서 2초간 빙글빙글 돌며 정지**, 풀이 과정 배너 3.5초 표시.
- 문제는 학생마다 랜덤 출제 (정수 역산 생성이라 정답이 항상 딱 떨어지고 부동소수점 오차가 없음).

## 배경
도심 거리(건물·가로수·횡단보도) → 시민공원 옆 도로(나무·화단·연못·산책로) → 강 위의 다리(난간·배·가로등) 구간이 이어집니다. 구간 정의는 `public/index.html`의 `ZONES`에서 바꿀 수 있어요.

## 코스 (커브)
톨게이트 사이 구간마다 커브가 하나씩 있고, 톨게이트 앞뒤 45m는 항상 직선입니다. 화면은 **차가 늘 위를 향하도록 지도가 돌아가는 시점**이라 U자로 돌아 나갈 때도 ←→ 조작이 그대로예요.
- **완만한 커브**: 몸풀기용
- **S자 커브**: 오른쪽·왼쪽·오른쪽으로 연달아 꺾이는 구간
- **F1 헤어핀 / 시케인 급커브**: 각지게 확 꺾이는 구간
- **U자 커브 2연속(180°)**: 크게 돌아 반대 방향으로 내려갔다가 다시 돌아 올라와요
- **200° 초대형 커브**: 반대쪽으로 살짝 꺾었다가 200° 크게 돌아 나가요

급커브·U자 바깥쪽에는 노란 화살표 표지판이 있고, 들어가기 전에 "↓ 브레이크" 경고가 뜹니다. 속도를 안 줄이면 벽에 부딪혀 감속돼요(멈춰서 갇히지는 않아요).

코스 순서: 완만 → S자 → U자 2연속 → **F1 롱 스트레이트(750m, 강 위 다리)** → S자 → 시케인 → 200° 커브 → S자 → 완만 → S자(다리 위) → 헤어핀 → 결승선.

롱 스트레이트는 3번째 문제 바로 뒤에 있어서 어려움 부스터(×2.3, 4.5초)를 받은 학생이 가장 유리해요. 그 톨게이트 앞에서 "다음은 긴 직선! 어려움 부스터가 가장 유리해요" 안내가 떠요. 다른 구간도 직선을 150m씩 늘려(`CFG.SEG_EXTRA`) 문제 사이 간격을 넓혔어요.
화면 시점은 `public/index.html`의 `VIEW`에서 바꿀 수 있어요: `TILT_DEG`(비스듬한 정도, 0이면 위에서 수직), `ZOOM`(작을수록 넓게), `CAR_Y`(차의 화면 세로 위치). 화면 회전 속도는 `CFG.CAM_MAX_TURN`이에요.

`public/index.html`의 `COURSE` 배열로 순서를, `CURVES`로 모양(구간 길이 `len`, 방향 각도 `pts`)을 바꿀 수 있어요. U자처럼 크게 도는 커브를 새로 넣을 때는 도로끼리 너무 가까워지지 않는지 확인하세요.

## 출제 범위 (6학년 2학기 소수의 나눗셈)
| 난이도 | 유형 |
|---|---|
| 쉬움 | 자릿수가 같은 (소수)÷(소수), 몫이 한 자리 자연수 |
| 보통 | 자릿수가 다른 (소수)÷(소수), (자연수)÷(소수) |
| 어려움 | 몫이 소수 첫째 자리인 나눗셈, 소수 두 자리끼리, 소수 한 자리 ÷ 소수 두 자리 |

모든 문제는 **정답이 자연수 또는 소수 첫째 자리까지 딱 떨어지게** 출제됩니다 (반올림·나머지 문제 없음).

## 폴더 구조
```text
math-racing-game/
├── package.json
├── server.js        # Express 서버, 기록 API, 교사용 인증
├── teacher.html     # 교사용 대시보드 (/teacher)
├── .gitignore
└── public/
    └── index.html   # 학생용 게임 (Canvas)
```

## Render 배포
1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render → **New + → Web Service** → 저장소 선택
3. Build Command `npm install` / Start Command `npm start`
4. **Environment**에 `TEACHER_PASSWORD` (교사용 비밀번호)를 꼭 설정합니다. 선택: `MAX_STUDENTS`(기본 24)
5. 배포 후 학생용 주소 `https://(앱이름).onrender.com`, 교사용 `https://(앱이름).onrender.com/teacher` (아이디는 아무거나, 비밀번호는 위 값)

> 무료 플랜은 15분 정도 접속이 없으면 잠들고, 다시 열 때 30~60초가 걸립니다. 수업 시작 5~10분 전에 교사용 페이지를 한 번 열어 서버를 깨워 두세요.
> 기록은 서버 파일(`data/records.json`)에 저장되지만 무료 플랜은 재배포·재시작 시 사라질 수 있습니다. 오래 보관하려면 Render Disk(유료) 또는 외부 DB가 필요합니다.

## 로컬 실행

```bash
TEACHER_PASSWORD=1234 npm start   # http://localhost:3000
```

## 밸런스 조정
`public/index.html` 상단의 `CFG` 한 곳만 고치면 됩니다.
- `LEVELS[n].mul / dur`: 난이도별 부스터 배율·지속 시간
- `SPIN_SEC`: 오답 회전 시간, `LAUNCH_V`: 문제 후 재출발 속도
- `MAX_V`, `ACCEL`, `TURN`: 차 성능
- 교사용 대시보드의 **난이도별 평균 풀이 시간·정답률**을 보고 조정하세요.
