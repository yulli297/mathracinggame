# 🏎️ 소수의 나눗셈 스피드 레이서 (6학년 2학기)

톨게이트에서 난이도를 고르고, 정답으로 부스터를 얻어 **10문제를 풀며 최단 시간에 완주**하는 학급용 웹 게임입니다.

## 규칙 요약
- 트랙 3,300m, 300m마다 톨게이트 10개 (문제 10개). 칸막이가 있는 3개 길 중 하나로 들어가면 난이도가 정해집니다.
- 문제를 푸는 동안 차는 멈추지만 **전체 타이머는 계속 흐릅니다.**
- 정답: 난이도별 부스터 (쉬움 ×1.3 2.0초 / 보통 ×1.6 3.0초 / 어려움 ×2.3 4.5초). 부스터 시간은 달리는 동안에만 줄어듭니다.
- 오답: 감속 없이 **그 자리에서 2초간 빙글빙글 돌며 정지**, 풀이 과정 배너 3.5초 표시.
- 문제는 학생마다 랜덤 출제 (정수 역산 생성이라 정답이 항상 딱 떨어지고 부동소수점 오차가 없음).

## 출제 범위 (6학년 2학기 소수의 나눗셈)
| 난이도 | 유형 |
|---|---|
| 쉬움 | 자릿수가 같은 (소수)÷(소수), 몫이 한 자리 자연수 |
| 보통 | 자릿수가 다른 (소수)÷(소수), (자연수)÷(소수) |
| 어려움 | 몫이 소수인 나눗셈, 소수 두 자리끼리, **몫 반올림**, **나머지 구하기** |


## Render 배포
1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render → **New + → Web Service** → 저장소 선택
3. Build Command `npm install` / Start Command `npm start`
4. **Environment**에 `TEACHER_PASSWORD` (교사용 비밀번호)를 꼭 설정합니다. 선택: `MAX_STUDENTS`(기본 24)
5. 배포 후 학생용 주소 `https://(앱이름).onrender.com`, 교사용 `https://(앱이름).onrender.com/teacher` (아이디는 아무거나, 비밀번호는 위 값)

> 무료 플랜은 15분 정도 접속이 없으면 잠들고, 다시 열 때 30~60초가 걸립니다. 수업 시작 5~10분 전에 교사용 페이지를 한 번 열어 서버를 깨워 두세요.
> 기록은 서버 파일(`data/records.json`)에 저장되지만 무료 플랜은 재배포·재시작 시 사라질 수 있습니다. 오래 보관하려면 Render Disk(유료) 또는 외부 DB가 필요합니다.

## 로컬 실행
```bash
npm install
TEACHER_PASSWORD=1234 npm start   # http://localhost:3000
```

## 밸런스 조정
`public/index.html` 상단의 `CFG` 한 곳만 고치면 됩니다.
- `LEVELS[n].mul / dur`: 난이도별 부스터 배율·지속 시간
- `SPIN_SEC`: 오답 회전 시간, `LAUNCH_V`: 문제 후 재출발 속도
- `MAX_V`, `ACCEL`, `TURN`: 차 성능
- 교사용 대시보드의 **난이도별 평균 풀이 시간·정답률**을 보고 조정하세요.
